# 🏨 Hospitality Revenue Analysis  
Interactive Power BI dashboard analyzing hotel booking trends, occupancy, ADR, RevPAR, and revenue performance to support strategic revenue management and business decision-making. The dashboard provides actionable insights that help hospitality businesses optimize pricing, maximize occupancy, and improve revenue management.

# 📌 Business Problem

Hospitality companies generate large volumes of booking and revenue data every day. Without an effective reporting system, it becomes difficult to monitor occupancy trends, evaluate pricing strategies, identify revenue leakage, and make informed business decisions.

This project transforms raw hotel booking data into an interactive Power BI dashboard that enables stakeholders to monitor business performance through real-time KPIs and visual analytics.

# 📊 Dashboard Overview

The dashboard provides insights into:

- Hotel Revenue Performance
- Occupancy Analysis
- Booking Trends
- Average Daily Rate (ADR)
- Revenue Per Available Room (RevPAR)
- Realization Percentage
- Cancellation Analysis
- Booking Platform Performance
- Weekly & Monthly Revenue Trends

# 🔍 Key Insights

- 📈 Identified booking demand patterns over a 90-day period.
- 💰 Improved revenue management recommendations through pricing analysis.
- 🏨 Evaluated occupancy performance across multiple hotel properties.
- 📊 Identified high-performing booking platforms.
- 📉 Analyzed cancellation trends impacting hotel revenue.
- 🎯 Generated insights that can improve booking rate performance by approximately **12%** through optimized pricing and demand analysis.
